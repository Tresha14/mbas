# MBAS Synthetic Dataset v1.0

Simulated multimodal interview and meeting data for the Multimodal Behavioural Analysis System.
Generated by `generator/generate_dataset.py` (seed 42). Regenerate or scale it with:

```
cd generator
python generate_dataset.py --participants 300 --meetings 100 --seed 7 --out ../mbas_synthetic_dataset_v2
python make_dictionary.py ../mbas_synthetic_dataset_v2
```

## What is inside

| Folder / file | Rows | Grain |
| --- | --- | --- |
| interview/participants.csv | 120 | one per participant (demographics, glasses, accent, split) |
| interview/sessions.csv | 289 | one per interview (device, lighting, noise, overall scores, recommendation) |
| interview/windows.csv | ~46,000 | one per 5 s window, 2.5 s hop (gaze, iris, head pose, blink, face, audio + attention/engagement labels) |
| interview/answers.csv | ~3,200 | one per answer (transcript, timing, fluency, prosody, MFCC, vision aggregates, content + all response labels) |
| interview/hesitation_events.csv | ~16,000 | time-stamped fillers, repetitions, restarts, hedges, long pauses, prolongations, blocks, delayed responses |
| interview/transcript_segments.csv | ~9,500 | question / answer / acknowledgement segments with timestamps |
| interview/conversation_turns.csv | ~9,500 | turn-taking with gaps, overlaps, interruptions |
| meeting/*.csv | 40 meetings | meetings, per-participant per-minute signals, turns, summaries + follow-ups, action items |
| annotations/*_annotator2.csv | 20% of sessions | second annotator labels (attention kappa 0.85, engagement kappa 0.75) |
| splits/*.csv | 84 / 18 / 18 | person-wise train / val / test participants |
| reference/question_bank.csv | 36 | HR, behavioural (STAR) and technical questions with key points and keywords |
| hidden_ground_truth/ | 120 | latent traits used by the simulator — for analysis only, never as model input |

Every column is described in `DATA_DICTIONARY.md`.

## How the data is simulated

Each participant has hidden traits (confidence, nervousness, preparedness, attentiveness, fluency, expressiveness, speech rate, accent strength, tendency to read from another screen). For every question, a knowledge level is drawn from preparedness minus question difficulty. These drive:

- **Transcripts:** answers are built from the question's key points (more covered when knowledge is high), vague and off-topic sentences, contradictions, and real disfluencies inserted word by word. Filler, repetition, restart and hedge counts are counted from the actual text.
- **Timing and voice:** latency, speaking rate, pauses, pitch, energy, jitter, shimmer, MFCC follow the traits plus noise.
- **Vision per window:** gaze, iris position, head pose, blinks and expressions depend on state (listening, thinking, answering), attentiveness, fatigue over the session, random distractions and reading behaviour.
- **Labels:** attention, engagement, relevance, quality, STAR, hesitation index, speaking pattern, five sub-scores, communication effectiveness and follow-up reason are computed from the signals with label noise.
- Practice effect across a participant's sessions; session conditions (device, lighting, background noise) affect detection confidence, SNR and ASR confidence.

## Which stage uses which file

| Stage | Use |
| --- | --- |
| 3 Pipeline | windowing, joins on session_id / answer_id, splits |
| 4–5 Vision | windows.csv: attention, engagement, gaze/iris targets and features for the attention-score model |
| 6 Speech | transcript_segments.csv: text for the SentencePiece tokenizer and KenLM language model |
| 7 Behaviour | answers.csv + hesitation_events.csv + conversation_turns.csv: hesitation index, speaking-pattern classifier |
| 8 Response + fusion | answers.csv (answer_text + question_bank) for the answer-quality model; all features for the fusion network; meeting/ for the meeting head |
| 10 Evaluation | annotations/ for kappa; participants.csv for bias checks |

## Important limitations

- This is **tabular, simulated** data: features and labels, not raw video or audio. The face detector, gaze CNN, engagement CNN-GRU, VAD and ASR still need images and audio — use the public raw datasets in Stage 2 (WIDER FACE, MPIIGaze, DAiSEE, LibriSpeech, Common Voice, SEP-28k) for those.
- Label it as synthetic in your report and viva. A small set of real recorded sessions for testing will make your results far more convincing.
- Relationships between signals are designed, so very high model scores mostly mean the model learned the simulator. Report results on the held-out test participants and keep label noise in.
